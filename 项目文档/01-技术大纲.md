# 旅游大王 · 技术大纲

## 1. 项目定位

旅游大王是一个 AI 文旅行程规划应用：用户填写目的地、日期与偏好后，系统自动检索景点素材、查询天气与酒店、计算预算与路线，最终生成一份带地图、知识图谱与预算明细的完整行程，并支持针对行程的 AI 追问与攻略图导出。

## 3. 系统架构

### 3.1 分层结构

```
┌─────────────────────── 浏览器 ───────────────────────┐
│ Landing（首屏 + 三步表单 + 历史记录）                 │
│ Result （行程概览 / 预算明细 / 景点地图 / 每日行程 /   │
│          知识图谱 / 天气信息 + 悬浮 AI 问答）          │
└───────────────┬─────────────────────────────────────┘
                │ 同源 HTTP / WebSocket（无跨域）
┌───────────────▼─────────────────────────────────────┐
│ FastAPI 服务（uvicorn，端口 7870）                    │
│ ├─ 路由层  /api/trip  /api/poi  /api/map             │
│ │          /api/chat  /api/settings  /api/memory      │
│ ├─ 服务层  xhs_service（景点素材/配图）                │
│ │          amap_service / google_map_service /         │
│ │          map_dispatcher / llm_service /              │
│ │          knowledge_graph_service / chat_service      │
│ ├─ 智能体  trip_planner_agent（主控 + 天气 + 酒店）     │
│ ├─ 记忆    memory_manager（偏好提取 / 衰减 / TOP-K）    │
│ └─ 静态资源 frontend/dist（构建产物由后端托管）         │
└───────────────┬─────────────────────────────────────┘
                │
   ┌────────────┴─────────────┬──────────────────────┐
   ▼                          ▼                      ▼
高德 MCP（uvx 子进程）    Node 签名引擎          外部 SaaS API
天气 / 酒店 / POI         小红书请求签名          DeepSeek / 高德 / 小红书
```

### 3.2 运行时拓扑

- **仅一个常驻服务**：uvicorn 同时提供 API 与前端静态资源，因此不需要额外的 Node 前端服务、反向代理或数据库。
- **按需子进程**：`uvx amap-mcp-server` 在生成行程时用于天气/酒店/POI 查询；`node` 在小红书请求时执行签名 JS。两者都由主服务拉起，无需单独启动，进程退出即回收。
- **进程守护**：以 macOS LaunchAgent（`ai.tripdesign.local`）方式运行，`RunAtLoad` 开机自启、`KeepAlive` 异常自动拉起，日志重定向到 `~/Library/Logs/TripDesign/tripstar.log`。

## 4. 关键数据流

### 4.1 行程生成（异步任务 + 并发取数）

```
浏览器 POST /api/trip/plan  →  立即返回 task_id（避免网关超时）
        │
        ├─ asyncio 后台任务 _run_trip_planning
        │     ├─ 并发阶段（asyncio.gather）
        │     │    ├─ xhs_service.search_xhs_attractions  小红书游记 → LLM 提纯景点 → 高德补齐坐标
        │     │    ├─ weather_agent（高德 MCP 天气工具）
        │     │    └─ hotel_agent（高德 MCP POI 工具）
        │     └─ 聚合阶段：三方上下文拼装 Planner Prompt → LLM 输出结构化 JSON
        │            └─ _parse_response 容错解析（清噪 / 修引号 / 截断补齐 / 必要时 LLM 修复）
        ├─ knowledge_graph_service.build_knowledge_graph 生成图谱节点与关系
        └─ 任务状态落盘 backend/data/trip_tasks/<task_id>.json

浏览器 GET /api/trip/status/{task_id}（轮询，前端约每 3 秒）
浏览器 WS  /api/trip/ws/{task_id}（可选，实时推送 processing/progress/完成）
```

### 4.2 景点配图（三级降级）

```
前端 loadAttractionPhotos()  串行、每次间隔 900ms、同一行程每个景点仅尝试一次
        │  GET /api/poi/photo?name=<景点>&city=<城市>
        ▼
① 小红书搜索 → 命中则取首图直链并立即下载字节落盘（直链带时效签名，必须预取）
② 小红书为空（限流）→ 高德 POI 照片接口兜底
③ 都没有 → 前端渲染设计过的占位块（图标 + 可换行景点名）
        │
        └─ 图片统一经 /api/poi/image?name=… 代理返回，绕过防盗链与时效签名
           （白名单仅允许 *.xiaohongshu.com / *.xhscdn.com / *.amap.com / *.autonavi.com）
配套保护：失败结果按关键词缓存 10 分钟；连续空结果触发 10 分钟搜索冷却，避免持续触发风控。
```

### 4.3 主题与外设联动

```
theme.ts（跟随系统 prefers-color-scheme，手动切换后写 localStorage）
   ├─ <html data-theme> → tokens.css 变量组切换（暗色 / 日间）
   ├─ Ant Design Vue → darkAlgorithm / defaultAlgorithm + 令牌
   ├─ 高德底图 → darkblue / normal（切换时 setMapStyle 实时生效）
   └─ ECharts 知识图谱 → 读取令牌计算值并重绘
index.html 内联脚本在首屏绘制前应用主题，避免暗色用户看到白闪。
```

## 6. 设计系统

| 维度 | 规范 |
| --- | --- |
| 主题 | 单一页面单主题；暗色为默认，日间为可选；两套变量组共用同一套语义令牌 |
| 强调色 | 全站仅一个强调色（品牌珊瑚橙），暗色 `#f2603c`、日间压深为 `#b33512` 以保证白底对比度 |
| 圆角 | 统一四档：8 / 12 / 16 / 20px，圆形交互元素用 full |
| 字体 | UI 与标题 Outfit Variable；数字（预算、温度、日期、计数）JetBrains Mono Variable；中文回落系统字体 |
| 结构 | 用 1px 细线与留白表达层级，替代满屏毛玻璃卡片 |
| 动效 | 只动 `transform` 与 `opacity`；统一缓动 `cubic-bezier(0.16,1,0.3,1)`；全局尊重 `prefers-reduced-motion` |
| 可访问性 | 焦点可见环、语义标签、`aria-label`、全页文字对比度实测 ≥ AA |

## 8. 关键设计决策

| 决策 | 原因 |
| --- | --- |
| 后端单服务同时托管前端构建产物 | 同源部署无需跨域与反向代理，本地部署只需一个进程；代价是前端改动需重新构建 |
| 异步任务 + 轮询 + WebSocket 双通道 | LLM 生成耗时长，同步接口易触发网关超时；先返回 `task_id` 再由前端观察进度 |
| 图片必须由后端代理并落盘 | 小红书图片直链带时效签名（约 1 分钟失效）且有防盗链，浏览器直连必然 403 |
| 景点配图三级降级（小红书 → 高德 → 占位） | 小红书搜索对自动化访问敏感，单一来源会导致整页无图；高德提供稳定兜底，占位保证版面不塌 |
| 自研行程预览轨道替代 Swiper | 第三方轮播在拖拽、缩放、懒加载场景下反复出现体验问题；自研轨道用进度条 + 拖动两种可控交互，行为可测 |
| 全站令牌化 + 单强调色 | 原样式混用 8 种圆角、5 个字族与两套强调色，令牌化后主题可整体切换、对比度可量化校验 |
| 运行时配置（设置弹窗）与 `.env` 双通道 | 换 Key 不必改文件重启；运行时保存的值优先级高于 `.env`，敏感字段以掩码返回 |

## 9. 已知限制与技术债

| 项 | 说明 | 影响 |
| --- | --- | --- |
| 小红书搜索限流 | 账号登录态有效（`user/me` 返回 `guest:false`），但搜索接口持续返回空结果；已由高德兜底 | 图片质量可能不如小红书精挑图 |
| Google Maps 路径未验证 | 需要 Google 云 Key 与代理，当前环境仅验证了高德链路 | 国外场景未实测 |
| 导出攻略图为浅色印刷风 | 与页面主题不一致（有意保留），配色已改为品牌色 | 视觉差异，非缺陷 |
| 首屏包体偏大 | ECharts 与 html2canvas 体积较大（构建提示 >500kB chunk） | 首屏加载约数秒，后续可做更细粒度懒加载 |
| 死代码 | `views/Home.vue`（885 行）已无路由引用；结果页样式块仍有约 28 条未使用规则 | 维护噪音 |
| 无自动化测试套件 | 当前验证靠脚本化浏览器（CDP）与接口实测，未固化为测试用例 | 回归依赖人工执行 |
