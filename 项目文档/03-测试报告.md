## 2. 测试方法

本项目没有现成的自动化测试套件，因此用**可复现的脚本化验证**替代人工目测，所有结论都能追溯到命令输出：

| 方法 | 实现 | 用途 |
| --- | --- | --- |
| 浏览器脚本化验证 | Chrome 无头 + CDP：真实派发 pointer/mouse 事件、读取计算样式与 DOM 度量 | 交互行为与布局验证 |
| 全页对比度扫描 | 遍历所有含文本元素，按 alpha 合成计算文字与背景的对比度，输出最差项 | 可访问性验证（WCAG AA） |
| 像素测量 | 自写 PNG 解码脚本统计截图平均亮度、暗部/亮部占比 | 主题一致性与明暗混搭检测 |
| 接口实测 | curl 直打后端接口与外部接口，比对返回码与内容 | 链路可用性验证 |
| 日志取证 | 检索服务日志中的阶段进度、降级路径、异常栈 | 根因定位 |

## 4. 缺陷记录与复验

本轮测试共发现并修复 9 个缺陷，均为可复现问题：

| 编号 | 现象 | 根因 | 修复 | 复验 |
| --- | --- | --- | --- | --- |
| DEF-01 | 原项目服务始终起不来，launchd 报 `78 EX_CONFIG` | 日志文件写在项目目录，launchd 无法打开该已存在文件 | 日志改到 `~/Library/Logs/` | 服务正常拉起（已对照实验定位） |
| DEF-02 | 「重启」时启动超时、端口被占 | uvicorn 优雅退出需等请求结束（实测约 40s），脚本立即重启 | 停止逻辑改为轮询等待进程真正退出（上限 45s） | 启动/停止/重启全流程通过 |
| DEF-03 | 行程预览拖动时图片「漂移」 | 浏览器原生图片拖拽幽灵图 + 悬停缩放 + 滚轮劫持 + 居中回弹四因素叠加 | 逐一禁用，并最终整体替换为自研轨道组件 | TC-16 / TC-17 通过 |
| DEF-04 | 景点名显示不全（如「成都大熊猫繁育研究基地」） | 占位图把景点名画成 SVG 文本（不换行）＋ 卡片标题单行省略 | 占位改为 DOM 节点、标题允许两行换行 | 7 个景点名 0 裁切 |
| DEF-05 | 景点图片长期不显示 | 小红书搜索对账号持续返回空结果（登录态有效），原实现仅有单一图源 | 新增高德备选图源 + 串行限速 + 空结果冷却 + 占位降级 | TC-31 ～ TC-34 通过 |
| DEF-06 | 日间模式下多处文字几乎不可读（最低 1.09 : 1） | 暗色主题写死的浅色文字残留在样式与内联样式里 | 令牌校准 + 54 处残留色收敛到令牌 | 日间最低对比度 5.03，未达标 0 |
| DEF-07 | 校验脚本误报页面横向溢出 | 把轮播中被裁剪的幻灯片计为溢出元素 | 判定改为「文档宽度 > 视口宽度」 | 三档视口均无溢出 |
| DEF-08 | 构建产物中高德安全密钥为空（地图会失效） | 构建时未注入 `VITE_AMAP_SECURITY_JS_CODE` | 新增 `frontend/.env` 固化构建期变量 | 构建产物校验含 JSCode |
| DEF-09 | 行程预览轨道完全不位移、拖动无效 | 测量得到的宽度/间距存成了普通变量，计算属性不会重算 | 改为响应式 `ref` | TC-11 ～ TC-14 通过 |

## 7. 结论

- P0 功能需求全部通过；P1/P2 需求除「Google Maps（未验证）」与「导出图为浅色印刷风（有意保留）」外均通过。
- 可访问性在两种主题下均满足 WCAG AA（最低 5.03 : 1），三档视口无横向溢出。
- 9 个缺陷全部修复并复验，无已知阻塞性问题。
- 结论：**通过测试，可进入验收**。
