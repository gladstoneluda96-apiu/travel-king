## 2. 迭代明细

### R0 复刻与本地部署

- **目标**：把上游项目完整复刻到 `TripDesign` 并跑通本地部署。
- **产出**：独立 Python 环境（uv + Python 3.10.20）、前端依赖与构建产物、独立 LaunchAgent（`ai.tripdesign.local`，端口 7870）、git 基线提交。
- **验证**：`/health` 正常、首页与结果页可访问；与原始部署（7860）并存互不影响。
- **遗留**：原始样式体系混乱（8 种圆角、5 个字族、明暗混搭）。

### R1 设计底座与落地页重设计

- **目标**：先立规范再改页面。
- **改动**：
  - 新增 `tokens.css`（颜色/字号/间距/圆角/动效/层级）与 `base.css`（重置、焦点、滚动条、减弱动效降级）
  - 删除 8,899 行第三方模板样式（实测仅 31 个类被使用，且集中在首屏与导航），移除 Google Fonts 外链，改为自托管 Outfit Variable + JetBrains Mono Variable
  - Ant Design Vue 接入暗色算法与令牌
  - 导航栏重写；落地页首屏改为非对称分栏，右栏使用**高德静态地图生成的真实路线图**（本地资源，替换原本从第三方演示站加载的背景图与云雾图）
  - 清理首屏 7 个死代码计算属性，滚动监听改为 `IntersectionObserver`
- **验证**：三档视口无溢出；最低对比度 5.89；配色收敛为 5 个令牌值；0 处长破折号。

### R2 结果页与 AI 问答纳入设计系统

- **目标**：让结果页、问答面板与落地页成为同一套设计语言。
- **改动**：
  - 结果页 1,600+ 行样式令牌化（色值与圆角全部收敛）
  - 去掉嵌套毛玻璃：外层容器透明化，六个板块各自成为细线面板；顶部板块切换改为吸顶
  - 语义修正：温度/星期/天气描述不再占用 `h1/h2/h3`
  - 数字统一等宽字体；景点卡片重写（去掉白底黑字主题翻转与手绘波浪）
  - AI 问答从彩虹动画组件重写为与主题一致的问答面板（1160 → 426 行，逻辑与文案键全保留）
  - 知识图谱配色从硬编码彩虹改为统一明度/饱和度的分类配色
- **验证**：结果页最低对比度 5.89；整页亮度 33.9 → 30.9；问答与图谱功能复测正常。

### R3 日间模式

- **目标**：在暗色之外提供日间主题，并允许用户切换。
- **改动**：`theme.ts`（跟随系统 + 手动切换 + `localStorage` 持久化）、首屏绘制前内联脚本防白闪、导航栏切换入口、Ant Design 双算法、地图底图与图谱配色联动、日间令牌对比度校准（含第三方组件链接色）。
- **验证**：系统暗色→初始暗色；点击→日间并持久化；重载保持；日间最低对比度 5.03；地图与图谱同步切换。
- **问题与修复**：日间模式下发现 54 处「暗色主题写死的浅色字」，最低对比度仅 1.09，已全部收敛。

### R4 轮播缺陷修复 + R5 改纯拖动

- **目标**：解决行程预览轮播反复出现的体验问题。
- **改动（R4）**：轮播由 3D 效果改为常规滑动 + 定宽；无图时改为可换行占位；搜图改串行限速并加限流冷却。
- **改动（R5）**：禁用浏览器原生图片拖拽、悬停缩放、滚轮劫持与居中回弹；起始位置对齐第一张。
- **验证**：拖动跟手且松手吸附；滚轮不再翻卡；无原生拖拽幽灵图。
- **结论**：连续两次修复后仍存在体验分歧，R7 决定整体替换。

### R6 一键启动脚本

- **目标**：把「部署」收敛成双击一次。
- **改动**：桌面 `启动旅游大王.command` / `停止旅游大王.command`；依赖自检（node / uvx / `.env`）、首次运行自动装配（虚拟环境 + 依赖 + 前端构建）、服务未注册时自动注册、幂等启动、失败时打印日志与端口占用提示；脚本归档进 `scripts/`。
- **验证**：启动 1.2s 内就绪；已在运行时提示不重复启动；停止/重启/状态/日志四个子命令可用。
- **问题与修复**：首次测试重启失败：uvicorn 优雅退出耗时约 40s 导致端口占用，已改为轮询等待进程退出。

### R7 行程预览改进度条轨道

- **目标**：用可控的自研交互彻底替代第三方轮播，并恢复用户要求的主体放大效果。
- **改动**：新增 `OverviewRail.vue`（卡片轨道 + 进度条拖动 + 左右箭头 + 计数 + 鼠标拖动 + 键盘可操作）；移除 Swiper 依赖与相关代码（含样式与初始化逻辑）；主体卡片按「离中心的距离」连续缩放/降透明度，并加强调描边与上浮。
- **验证**：进度条拖到第 5 张 → 计数与居中卡片同步；拖动跟手并吸附；scale 1.00 / 0.93 / 0.88；尺寸变化用 `ResizeObserver` 重算。
- **问题与修复**：首版把测量值存成普通变量导致位移恒为 0，改为响应式后通过。

### R8 配图高德兜底

- **目标**：解决「图片总是不显示」。
- **根因**：小红书登录态有效（`user/me` 返回 `guest:false`），但搜索接口对所有关键词持续返回空结果（限流），原实现只有单一图源。
- **改动**：新增高德 POI 照片兜底；图片代理白名单加入高德域名；前端搜图改串行 + 900ms 间隔 + 每行程仅尝试一次；后端空结果 10 分钟冷却；无图渲染设计过的占位块。
- **验证**：7/7 景点图片可显示（第 7 张由浏览器懒加载，进入视口后加载）。

### R9 品牌更名

- **目标**：项目更名为「旅游大王」。
- **改动**：三语文案（标题、品牌、副标、页脚、问答欢迎语、导出页脚）、导航字标（TripKing）、页面标题、后端应用名与 AI 提示词、桌面与项目内脚本改名。
- **验证**：浏览器标签为「旅游大王」；页面正文不再出现旧品牌；`/health` 返回 `"service": "旅游大王"`。
- **有意保留**：GitHub 链接与导出图二维码仍指向上游仓库（GPL 源码归属）；内部技术标识（`localStorage` 主题键、LaunchAgent 标识、日志目录）保持不变以免丢失用户状态与需重新注册服务。
